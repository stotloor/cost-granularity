# Project Cost Granularity Controller — frontend

Generated by ApexStudio. Standard Vite + React + Tailwind project you fully own.

## Run it

```bash
npm install
# talk to the generated backend (see ../backend); leave unset to use the mock:
VITE_API_URL=http://localhost:8000 npm run dev
```

Then open the URL Vite prints (default http://localhost:5174).

## Structure

- `src/App.jsx` - the generated application
- `src/lib/apex*.js` - the data layer (client for the backend + preview mock)
- `src/main.jsx` - React entry point
- `src/index.css` - Tailwind directives

With `VITE_API_URL` set, the app talks to its FastAPI backend; with it unset it
runs against an in-memory mock so you can demo without the backend.
